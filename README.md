# vpn-setup

Свой сервер 3X-UI + Xray одной командой: защита сервера и три профиля для каждого пользователя.

| Профиль | Порт | Когда выручает |
|---|---|---|
| **Reality-XHTTP** (VLESS + XHTTP + REALITY) | 443/tcp | Основной: выглядит как HTTPS к настоящему сайту |
| **Sudoku-VLESSenc** (VLESS Encryption + FinalMask Sudoku) | 8443/tcp | Если провайдер режет по SNI: TLS и SNI нет, поток замаскирован |
| **XHTTP-VLESSenc** (VLESS Encryption + XHTTP) | 8080/tcp | Запасной: HTTP-запросы с зашифрованным содержимым |

## Запуск

На **чистом** сервере Ubuntu 22.04 / 24.04 / 26.04 (amd64 или arm64), от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/<АККАУНТ>/vpn-setup/main/install.sh)
```

Скрипт спросит только имена пользователей и SSH-ключ (строка `ssh-ed25519 AAAA…` из MobaKeyGen). Около 3–5 минут.

После установки:

```bash
cat /root/vpn-setup/README.txt      # логин панели, как зайти через туннель, где лежат файлы
```

Скачай через SFTP MobaXterm папку `/root/vpn-setup/qr/` и файл `/root/vpn-setup/links.txt`.

## Что делает

1. Обновляет систему, ставит ufw, fail2ban, qrencode.
2. Добавляет SSH-ключ (если передан). Пароли **не** отключает — это отдельная команда с проверкой (ниже).
3. Выключает IPv6, включает BBR, создаёт swap 1 ГБ, если памяти мало.
4. Ставит 3X-UI **закреплённой версии v3.8.5** с проверкой SHA-256. Панель слушает только `127.0.0.1` со случайным портом, путём, логином и паролем. Подписка выключена.
5. Подбирает сайт для маскировки Reality (TLS 1.3 + h2, не Cloudflare).
6. Firewall: снаружи только SSH, 443, 8443, 8080. fail2ban на SSH.
7. Через API панели создаёт три inbound'а и пользователей, проверяет, что Xray принял конфиг (иначе выключает новые inbound'ы и не роняет остальные).
8. Делает QR-коды, бэкап базы, итоговую проверку портов.

## Частые действия

| Задача | Команда |
|---|---|
| Добавить людей | `USERS="HOME_PC Lusya Новое_имя" bash install.sh` — старые ссылки не меняются |
| Закрыть вход по паролю | Сначала войди по ключу в **новой** сессии, затем `bash install.sh harden-ssh`. Скрипт откажется, если в журнале не было ни одного `Accepted publickey` |
| Другой сайт маскировки | `SNI=www.example.de bash install.sh` (только на новом сервере: ссылки Reality изменятся) |
| Зайти в панель | MobaXterm → Tunneling → Local port forwarding на порт из README.txt → `http://127.0.0.1:ПОРТ/ПУТЬ/` |

Не нажимай в меню `x-ui` пункт **Update**: версия закреплена, потому что обновления панели уже ломали inbound'ы.

## Ограничения

- Скрипт **остановится**, если на сервере уже есть 3X-UI, поставленный вручную, — чтобы ничего не сломать. Он для новых серверов.
- Если IP сервера заблокирован у провайдера целиком, никакой профиль не поможет — нужен другой IP или хостер. Проверка до установки: `curl -s --max-time 5 telnet://IP:22` с домашнего ПК без VPN должна вернуть `SSH-2.0-…`.
- Профиль Sudoku работает только в клиентах, понимающих параметр `fm=` в ссылке (проверено: Throne, Happ, v2rayNG).

## Для разработки

`install.sh` собирается из `install.sh.in` и `lib/provision.py`: `bash build.sh`. Редактируй исходники, затем пересобери и закоммить `install.sh`.

Проверено в песочнице Ubuntu 24.04: полный прогон, повторный запуск с новым пользователем, трафик 300 КБ через все три профиля по ссылкам, сгенерированным панелью.
