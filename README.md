# vpn-setup

Свой VPN-сервер на 3X-UI + Xray одной командой: защита сервера и три профиля на каждого пользователя. В приложении профили видны с флагом страны сервера: `🇩🇪 Reality-XHTTP-Имя`.

| Профиль | Порт | Когда выручает |
|---|---|---|
| **Reality-XHTTP** (VLESS + XHTTP + REALITY) | 443/tcp | Основной: выглядит как HTTPS к настоящему сайту |
| **Sudoku-VLESSenc** (VLESS Encryption + FinalMask Sudoku) | 8443/tcp | Провайдер режет по SNI: TLS и SNI нет, поток замаскирован |
| **XHTTP-VLESSenc** (VLESS Encryption + XHTTP) | 8080/tcp | Запасной: HTTP-запросы с зашифрованным содержимым |

## Установка

На **чистом** сервере Ubuntu 22.04 / 24.04 / 26.04 (amd64 или arm64), от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/beepbeepgreench/hello-ui-bye-rkn/main/install.sh)
```

Скрипт спросит:
1. Имена пользователей (латиница).
2. Публичный SSH-ключ — строка `ssh-ed25519 AAAA…` (можно пропустить).
3. **Сайт маскировки Reality** — покажет проверенный список, Enter = лучший; можно вписать свой домен — он будет проверен.

3–7 минут. После установки на сервере появится короткая команда **`vpn-setup`** (подсказка с командами показывается при каждом входе на сервер).

## Как зайти в панель 3X-UI (важно для новичков)

Панель **специально закрыта снаружи** — открыть её по адресу `http://IP:порт` в браузере нельзя, это защита.
Заходят через **SSH-туннель**: он делает так, что панель сервера открывается на твоём компьютере по адресу `127.0.0.1`.

На сервере выполни **`vpn-setup panel`** — команда напечатает адрес, логин, пароль и готовые шаги с твоими портами для:

| Чем пользуешься | Как сделать туннель |
|---|---|
| Windows 10/11, macOS, Linux | Одна команда в терминале: `ssh -N -L ПОРТ:127.0.0.1:ПОРТ root@IP` — окно не закрывать, пока работаешь с панелью |
| MobaXterm (Windows) | Tunneling → New SSH tunnel → Local port forwarding (поля подставь из `vpn-setup panel`) → Start |
| PuTTY (Windows) | Connection → SSH → Tunnels: Source port = ПОРТ, Destination = 127.0.0.1:ПОРТ → Add → Open |
| Телефон (Android/iOS) | Termius → Port Forwarding → Local |

Потом в браузере: `http://127.0.0.1:ПОРТ/ПУТЬ/`. Самые частые ошибки: туннель не запущен/закрыт; набран IP сервера вместо `127.0.0.1`; VPN-клиент в режиме TUN перехватывает SSH.
Windows пишет «ssh не найден» → Параметры → Приложения → Дополнительные компоненты → добавить «Клиент OpenSSH».

## Команды после установки

`vpn-setup help` — полный список. Главное:

| Команда | Что делает |
|---|---|
| `vpn-setup panel` | Как зайти в панель: адрес, логин, пароль и шаги для туннеля |
| `vpn-setup links [ИМЯ]` | Ссылки для приложений и QR-коды (`/root/vpn-setup/qr/`) |
| `vpn-setup harden-ssh` | Отключить вход по паролю. **Сделай после первого входа по ключу.** Откажется, если входа по ключу ещё не было |
| `vpn-setup status` | Проверка здоровья сервера (что значат пункты — ниже) |
| `vpn-setup sni` | Сменить сайт маскировки (ссылки Reality изменятся) |
| `vpn-setup domain ДОМЕН` / `domain off` | Свой домен: самая сильная маскировка (раздел ниже) |
| `vpn-setup backup` / `uninstall` | Бэкап сейчас (ежедневный идёт сам) / удаление с финальным бэкапом |

Добавить людей: `USERS="новое_имя" vpn-setup` — старые пользователи и их ссылки сохраняются.

### Пункты `vpn-setup status` с «!» — что делать

| Сообщение | Что значит и что делать |
|---|---|
| вход по паролю ВКЛЮЧЁН | Пока любой может подбирать пароль. Зайди по ключу в новой сессии → `vpn-setup harden-ssh` |
| нужна перезагрузка | Установлены обновления безопасности ядра/библиотек, они заработают после `reboot`. VPN пропадёт на 1–2 мин — делай ночью |
| бэкапов нет / старый бэкап | `vpn-setup backup` |
| версии: 3X-UI … устарела | Вышла версия скрипта с новой панелью. Запусти `vpn-setup` — обновит с бэкапом и автооткатом |
| версии: 3X-UI … новее проверенной | Нажали «Обновить» в панели. Работает — не трогай; кнопку больше не нажимай |

## Перед покупкой/настройкой: не режет ли твой провайдер этот IP

Провайдеры в РФ часто полностью блокируют IP зарубежных хостингов. Проверь за 5 минут (с ПК, VPN выключен):

1. MobaXterm → Start local terminal: `bash check-server.sh IP_СЕРВЕРА` (файл `check-server.sh` из репозитория). «SSH-данные не доходят» → этот IP не подойдёт.
2. На сервере: `bash <(curl -fsSL https://raw.githubusercontent.com/beepbeepgreench/hello-ui-bye-rkn/main/install.sh) precheck`, затем Enter в `check-server.sh`. «IP рабочий» → ставь.

Без `check-server.sh` — одна строка в PowerShell после установки: `curl.exe -s -o NUL -w "%{http_code}" http://IP:8080/` → `404` = доступен, `000` = режется.

## Свой домен — самая сильная маскировка (по желанию)

Обычно Reality «притворяется» чужим сайтом (например, `www.otto.de`). Слабое место: этот сайт на самом деле живёт на других IP, и при сверке «имя сайта ↔ IP» подмену можно заметить.
Со своим доменом сервер притворяется **сам собой**: домен указывает на IP сервера, у сайта настоящий сертификат Let's Encrypt, и любой, кто откроет `https://твой-домен` или проверит сервер (сканер, ТСПУ, браузер), увидит обычный маленький сайт-блог. VPN-клиенты при этом подключаются как раньше.

**Что нужно:**
1. Домен, купленный **специально для этого** — отдельный, нейтральный (например `lena-photo-notes.com`). Лучше зарубежная зона: `.com .net .org .eu .de` и т.п.
2. В DNS домена — **A-запись на IP сервера** (и никаких других A/AAAA-записей). Если DNS в Cloudflare — переключи облако в **«DNS only»** (серое).
3. Подождать 5–30 минут, пока запись разойдётся, затем на сервере:
   ```
   vpn-setup domain lena-photo-notes.com
   ```
   (или сразу при установке: `DOMAIN=lena-photo-notes.com bash <(curl -fsSL …/install.sh)`)
   Скрипт проверит DNS, поставит nginx, сделает сайт-заглушку, выпустит сертификат (продлевается сам) и переключит Reality. **Ссылки Reality изменятся** — раздай новые: `vpn-setup links`.

**Какие домены НЕ брать:**
- со словами vpn, proxy, trojan, vless, xray, wg, tunnel, обход и т.п. — такие ловят первыми (скрипт откажется);
- домен своего бизнеса, магазина, личного сайта — если РКН заблокирует домен, пострадает и бизнес, а VPN будет привязан к твоему имени;
- `.ru / .рф / .su` — работает, но регистратор обязан приостановить домен по требованию РКН (скрипт предупредит).

Сайт лежит в `/var/www/ДОМЕН` — можно заменить своими файлами, скрипт их не перезапишет. Порт 80 открывается для продления сертификата.
Вернуться к чужому сайту: `vpn-setup domain off` (сертификат и файлы сайта остаются).

## Что делает и чего не делает

**Делает:** обновления и автообновления безопасности; SSH-ключ; firewall (наружу только SSH и три VPN-порта, порт текущей SSH-сессии гарантированно остаётся); fail2ban на SSH (твой IP в исключениях); IPv6 off (если ты подключён не по IPv6), BBR, swap; 3X-UI закреплённой версии с проверкой SHA-256; панель только на `127.0.0.1` со случайными портом/путём/логином/паролем; подписка выключена; проверка, что Xray принял конфиг; QR-коды; ежедневные бэкапы.

**Не делает:**
- Не отключает пароли сам — это `vpn-setup harden-ssh` после проверки ключа (иначе можно потерять доступ).
- Не обновляет 3X-UI/Xray сам. Версия закреплена и проверена; **кнопку «Обновить» в панели и Update в меню `x-ui` не нажимай** — откатить такое обновление нельзя. Новая версия приходит с новой версией скрипта: `vpn-setup` сделает бэкап, обновит панель, проверит, что пользователи и inbound на месте, а при сбое сам вернёт старую версию.
- Не спасает от блокировки IP провайдером, DDoS и злоупотреблений пользователей.
- Не ставится поверх 3X-UI, установленного вручную.

Профиль Sudoku работает в клиентах, понимающих параметр `fm=` в ссылке (проверено: Throne, v2rayNG, Happ — на свежих версиях).

## Если что-то пошло не так

- **Остановилось на шаге 1 (apt):** запусти ещё раз — повторный запуск безопасен.
- **Сайт маскировки:** `SNI=www.example.de vpn-setup`; если уверен в сайте, а проверка ошибается: `SNI_SKIP_CHECK=1`.
- **Страна/флаг определились неверно:** `COUNTRY=FR vpn-setup`.
- **Любая ошибка:** пришли последнюю строку `ОШИБКА: …` и вывод `vpn-setup status`.
