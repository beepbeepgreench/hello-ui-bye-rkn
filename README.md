# vpn-setup

Свой VPN-сервер на 3X-UI + Xray одной командой: защита сервера и три профиля на каждого пользователя.

| Профиль | Порт | Когда выручает |
|---|---|---|
| **Reality-XHTTP** (VLESS + XHTTP + REALITY) | 443/tcp | Основной: выглядит как HTTPS к настоящему сайту |
| **Sudoku-VLESSenc** (VLESS Encryption + FinalMask Sudoku) | 8443/tcp | Провайдер режет по SNI: TLS и SNI нет, поток замаскирован |
| **XHTTP-VLESSenc** (VLESS Encryption + XHTTP) | 8080/tcp | Запасной: HTTP-запросы с зашифрованным содержимым |

## Перед установкой: проверь, что IP сервера не заблокирован

С домашнего ПК **без VPN** (PowerShell):

```powershell
curl.exe -s --max-time 5 telnet://IP_СЕРВЕРА:22
```

Должна прийти строка `SSH-2.0-OpenSSH…`. Если пусто — провайдер режет этот IP, никакой профиль не поможет: попроси у хостера другой IP или возьми сервер у другого хостера.

## Установка

На **чистом** сервере Ubuntu 22.04 / 24.04 / 26.04 (amd64 или arm64), от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/beepbeepgreench/hello-ui-bye-rkn/v1.0.0/install.sh)
```

Ссылка ведёт на **зафиксированный релиз** `v1.0.0` — содержимое по ней не меняется.

Скрипт спросит:
1. Имена пользователей (латиница).
2. Публичный SSH-ключ — строка `ssh-ed25519 AAAA…` из MobaKeyGen (можно пропустить).
3. **Сайт маскировки Reality** — покажет проверенный список (включая «соседей» сервера по подсети), можно выбрать номер или вписать свой домен: он будет проверен (TLS 1.3, h2, X25519, сертификат, не Cloudflare/CDN, без чужих редиректов).

Около 3–7 минут. Итог: `cat /root/vpn-setup/README.txt` — логин панели, как зайти через туннель, где файлы.
Скачай через SFTP папку `/root/vpn-setup/qr/` и файл `/root/vpn-setup/links.txt`.

## Команды после установки

```bash
bash /root/vpn-setup/install.sh help
```

| Команда | Что делает |
|---|---|
| `harden-ssh` | Отключает вход по паролю. Откажется, если ещё не было ни одного входа по ключу |
| `sni` / `sni www.example.de` | Сменить сайт маскировки (выбор из списка или свой домен с проверкой). Ссылки Reality изменятся |
| `status` | Проверка здоровья: сервисы, порты, firewall, fail2ban, SSH, бэкапы, обновления |
| `links [ИМЯ]` | Показать ссылки, пересоздать QR |
| `backup` | Бэкап базы и ключей сейчас (ежедневный идёт автоматически, хранятся 14) |
| `uninstall` | Удалить панель и VPN-правила firewall; SSH и защита остаются; финальный бэкап сохраняется |

Добавить людей: `USERS="старые имена новые" bash /root/vpn-setup/install.sh` — старые ссылки не меняются.

## Что делает и чего не делает

**Делает:** обновляет систему и включает автообновления безопасности; SSH-ключ; firewall (наружу только SSH и три VPN-порта, правило для текущей SSH-сессии гарантированно остаётся); fail2ban на SSH (твой текущий IP в исключениях); IPv6 off, BBR, swap при нехватке памяти; 3X-UI закреплённой версии с проверкой SHA-256; панель только на `127.0.0.1` со случайными портом, путём, логином и паролем; подписка выключена; проверка, что Xray принял конфиг; QR-коды; ежедневные бэкапы.

**Не делает:**
- Не отключает вход по паролю сам — это `harden-ssh` после проверки ключа (иначе можно потерять доступ).
- Не обновляет 3X-UI/Xray: версия закреплена, потому что обновления панели уже ломали inbound'ы. Не нажимай в меню `x-ui` пункт Update. Новые версии выходят новым релизом этого скрипта.
- Не защищает от DDoS, от блокировки IP провайдером и от злоупотреблений пользователей (торренты блокируются, но остальное — на твоей ответственности).
- Не ставится поверх 3X-UI, установленного вручную, — остановится, чтобы ничего не сломать.

Профиль Sudoku работает только в клиентах, понимающих параметр `fm=` в ссылке (проверено: Throne; v2rayNG и Happ — проверяй на своей версии).

## Если что-то пошло не так

- **Остановилось на шаге 1 (apt):** скрипт ждёт до 10 минут, пока сервер закончит первичную настройку; если всё равно упало — запусти ещё раз.
- **Подключаешься к серверу по IPv6:** скрипт это видит и IPv6 не отключает, чтобы не оборвать твою сессию.
- **Скрипт сам не может подобрать сайт маскировки:** `SNI=www.example.de bash install.sh`; если уверен в сайте, а проверка ошибается: `SNI_SKIP_CHECK=1`.
- **Любая ошибка:** пришли последнюю строку `ОШИБКА: …` и вывод `bash /root/vpn-setup/install.sh status`. Повторный запуск безопасен.

## Для разработки

`install.sh` собирается из `install.sh.in` и `lib/`: `VERSION=v1.0.0 bash build.sh`. Тесты модулей: `tests/*/run.sh`. Релиз: собрать, закоммитить `install.sh`, поставить тег, совпадающий с `VERSION`.
